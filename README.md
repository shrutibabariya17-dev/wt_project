# Student Hub

## Description

Student Hub is a simple website developed using HTML and CSS. It provides students with easy access to campus information, course enrollment, events, administrative services, and other useful resources through a simple navigation menu.

## Technologies Used

* HTML
* CSS

## Project Pages

* Home
* Administrative
* Campus Life
* Course Enrollment
* Login
* Registration
* Events
* Dashboard
* About Us
* Contact Us

## How to Run

1. Open the project folder.
2. Open `index.html` in any web browser.
3. Navigate through the website using the menu.
